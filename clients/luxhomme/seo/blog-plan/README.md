### Ритм

- Черновик готов за 5 дней до публикации, Ираклий вычитывает за 2 дня, публикация по команде.
- Руководства по моделям пишем по Word-инструкциям клиента. Если их нет к сроку черновика, берём PDF-инструкции с сайта. Запросить у клиента все инструкции до 01.12.
- Статьи на 31.12, 05.01 и 07.01 ставим отложенной публикацией в WordPress заранее, после согласования.
- Резерв, если статья не готова: черновик клиента в WP «Как сделать домашние дела проще: 5 привычек для комфортного дома» (5678741, сентябрь).

### В день публикации

1. Заголовок записи до 59 знаков, «Отрывок» 140–160 знаков: из него витрина берёт meta description.
2. Alt у картинок прописан в самой статье (в HTML), а не только в медиатеке.
3. Переобход страницы в Вебмастере: пока статей нет в sitemap, без этого статья долго не попадёт в индекс.
4. Анонс в Дзене и Telegram-канале, ссылка из ближайшей рассылки.

## Требования к каждой статье

- HTML-статья в блоге, H1 из плана, title до 60 символов, description до 160 символов с ценой «от … ₽» или выгодой.
- Блок товара с ценой и кнопкой «В корзину» после первого экрана и в конце; цены тянуть из каталога, не вписывать руками.
- 2–3 ссылки на статьи блога из таблицы и ссылка на хаб 01.12 из всех новогодних статей.
- В руководствах по моделям: подзаголовки под реальные вопросы («Как включить музыку», «Насадка для окон», «Что делать, если…»), блок FAQ, ссылка на PDF для скачивания.
- Разметка Article и FAQPage, alt у всех картинок, статья в sitemap.
- В день публикации: переобход в Вебмастере, анонс в Дзене и Telegram-канале.
