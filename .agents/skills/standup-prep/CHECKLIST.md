# Daily Standup Prep — Acceptance Checklist

- [ ] The prep note is understood by the user as preparation only — it does not replace the actual Daily Scrum meeting.
- [ ] The metadata includes the date, sprint number, sprint goal, and person's name.
- [ ] The "Yesterday" section states completed or advanced work in terms relevant to team awareness, not a raw task log.
- [ ] The "Today" section states planned work as an intention (not a guarantee).
- [ ] The "Blockers" section either names at least one blocker with a responsible owner, or explicitly records "None."
- [ ] Any verbal notes are captured as brief prompts, not as a duplicate of the written sections.
- [ ] The output cites the canonical Scrum Guide reference URL (`https://scrumguides.org/scrum-guide.html`).
- [ ] The "Source consulted" section records which mode was used (offline or online) and does not include fabricated quotations or page numbers.
- [ ] The facilitation dialogue is in the language at `language.communication`, and the saved artifact is in the language at `language.output` (falling back to `language.communication` if `language.output` is absent or empty).
- [ ] The artifact is saved to `docs/pm-kit/outputs/standup-prep/<slug>.md` and begins with the three-line provenance header.

> Mark **PASS** or **FAIL**. On **FAIL**, return to the skill with notes.
