## 1. Правила работы

- Язык русский. В текстах без длинных тире.
- Цифры только из данных клиента, ничего не придумывать. Суммы и итоги перепроверять по дням и по строкам.
- ЯД (Яндекс Директ) и ЯМ (медийка Яндекс Маркета) не смешивать. Контент-завод (блогеры) считается отдельно от ЯД.
- Вторичные метрики (ДРР, CTR, конверсии, средний чек, CPO, цена просмотра) только формулами из metrics.md, в таблицах тоже формулами.
- Таблицы без лишних комментариев и предупреждений.
- Новые данные дописывать в data/ГГГГ-ММ.md нужного месяца.
- На сайте ничего не менять без подтверждения. Статьи не публиковать без команды.
- Пароли и ключи в чат не просить и не выводить. Вебхук Битрикс24 тоже секрет.

| Метрика                    | Формула                          |
|----------------------------|----------------------------------|
| ДРР                        | Расходы / Выручка × 100%         |
| ДРР средневзвешенный       | Σ Расходов / Σ Выручки × 100%    |
| CTR                        | Клики / Просмотры                |
| Конверсия клики → корзины  | Корзины / Клики                  |
| Конверсия корзины → заказы | Заказы / Корзины                 |
| Средний чек                | Выручка / Заказы                 |
| Цена просмотра             | Расходы / Просмотры              |
| CPO                        | Расходы / Заказы                 |
| Разница в %                | (Новое − Старое) / Старое × 100% |

Таблица «Меморандум 1 млрд» (Google Sheets, вкладка «Меморандум»): строки 8–27 блок ЯД, 28–35 контент-завод. Август: колонки T–X по неделям; сентябрь: AI план, AJ–AN недели. S-кривая бюджета по неделям: ~9,5% / 19,7% / 30,7% / 30,7% / 9,5%.

## 4. Заказы Ozon с UTM и затратами Директа (01.08–31.10)

Задача: свести заказы Ozon двух кабинетов, найти заказы с UTM-метками (Яндекс Директ, соцсети, блогеры) и разнести на них расход Директа.

### Источники

- Выгрузки заказов Ozon FBO и FBS обоих кабинетов. В FBS обоих кабинетов только доставленные заказы, отмен нет.
- Отчёты «Внешний трафик» обоих кабинетов: кабинет 1 (ID 2621643) 136 заказанных товаров, кабинет 2 (ID 253615) 362. Номеров заказов в отчётах нет.
- Статистика Яндекс Директа «Отчёт по всем кампаниям» 01.08–31.10, расход по дням.

### Как сопоставлено

- Заказ привязан к строке отчёта, если совпадает предельная цена и дата заказа равна дате клика (в рамках сессии) или до 30 дней после неё (окно атрибуции). При нескольких кандидатах приоритет у того же артикула и более ранней даты. Каждый отчёт сопоставляется только с заказами своего кабинета.
- Если в строке несколько товаров по разным ценам, подбираются заказы, чьи цены в сумме точно дают сумму строки (36 заказов, пометка «подбор по сумме строки»).
- «Luxhommè» и «Luxhommè store» в поле «Откуда заказ» считаются площадкой «Сайт»; «Ozon», «Шопинг в Т-Банке», «ВТБ Шопинг» площадкой ОЗ.
