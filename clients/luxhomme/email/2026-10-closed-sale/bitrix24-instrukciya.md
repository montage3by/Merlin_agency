# Как отправить письмо «Закрытая распродажа −15%» через Битрикс24

Для облачного Битрикс24. Названия пунктов меню в разных версиях немного отличаются — ориентир по смыслу.

## Где находится рассылка

Левое меню → **CRM** → **Маркетинг** (в новых версиях «Маркетинг» — отдельный пункт левого меню) → **Рассылки** → **Email**.

Если раздела «Маркетинг» нет:
- он скрыт в меню — нажать «Ещё» внизу левого меню;
- у пользователя нет прав — права выдаёт администратор портала (CRM → Настройки → Права доступа → Маркетинг);
- инструмент не включён в тарифе — проверить у администратора портала.

## Перед запуском

- [ ] Промокод заведён на сайте и вписан в письмо (вместо заглушки `CLOSED15`).
- [ ] Картинки письма лежат по публичным ссылкам (в `email.html` нет адресов вида `images/...`).
- [ ] Адрес отправителя на домене `luxhomme.store`, для домена настроены SPF и DKIM.
- [ ] Определено, кому отправляем (подписчики с согласием / вся база — см. переписку), текст письма соответствует.

## Шаг 1. Сегмент получателей

Маркетинг → **Сегменты** → **Добавить сегмент**:
1. Название: «Закрытая распродажа 10.2026».
2. Источник: контакты CRM (при необходимости — также лиды и компании).
3. Фильтр: есть email; согласие на рассылку (если такое поле есть в CRM).
4. Сохранить и посмотреть число адресов в сегменте.

Отписавшиеся исключаются Битрикс24 автоматически.

## Шаг 2. Создать рассылку

Маркетинг → Рассылки → Email → **Создать**.

| Поле | Что указать |
|---|---|
| Название | Закрытая распродажа −15% · 10.2026 |
| Отправитель | Имя «Luxhommè», адрес на домене luxhomme.store. Новый адрес добавляется в этом же поле — Битрикс24 пришлёт на него код подтверждения |
| Тема | Ваш код на −15% внутри: только для подписчиков |
| Прехедер (если есть поле) | Код только для подписчиков. Работает на всю технику до 30 октября. |

## Шаг 3. Вставить письмо

1. В блоке «Сообщение» выбрать шаблон **«Без шаблона»** / **«Пустой»** (или вариант «HTML»).
2. Переключить редактор в режим **HTML-кода** (кнопка `HTML` / `<>` на панели редактора).
3. Удалить всё, что там есть, и вставить содержимое файла `email.html` целиком.
4. Переключиться обратно в визуальный режим только для просмотра. **Ничего не править в визуальном режиме** — редактор ломает табличную вёрстку. Правки — только в HTML-коде.

## Шаг 4. Получатели

Блок «Получатели» → **Добавить сегмент** → выбрать сегмент из шага 1. Во «Исключить» — сегменты, которым письмо не нужно (сотрудники, тестовые контакты).

## Шаг 5. Тест

Кнопка **«Отправить тестовое письмо»** → 3–4 адреса: Gmail, Яндекс, Mail.ru, почта на iPhone.

Проверить в каждом:
- картинки загрузились;
- промокод верный, кнопки «Скопировать», «Выбрать со скидкой» и карточки товаров ведут на сайт;
- ссылка «Отписаться» работает (в письме стоит макрос `#UNSUBSCRIBE_LINK#` — Битрикс24 подставляет ссылку сам);
- письмо не попало в «Спам» / «Промоакции».

## Шаг 6. Запуск

- **Отправить** — сразу, или **Запланировать** — дата и время.
- Рекомендуемое время: будний день, 10:00–12:00 по Москве, не позже 23–24.10, чтобы до 30.10 осталась неделя.
- Большая база и первая массовая рассылка с домена — отправлять частями: сначала активные покупатели, через 1–2 дня остальные.

## Шаг 7. Результаты

Через 2–3 дня: Маркетинг → Рассылки → открыть рассылку → **статистика** (доставлено, открытия, клики, отписки, жалобы).

Заказы с промокодом — в WooCommerce (Заказы → фильтр по купону) и в Метрике по метке `utm_campaign=closed_sale_2026_10`.
