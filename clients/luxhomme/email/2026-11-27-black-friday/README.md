## Перед отправкой

1. Цены сняты с сайта 26.11 вечером. Утром 27.11 пересобрать: `python3 -I scripts/build_email.py build`, если цены изменились, вставить HTML в Битрикс24 заново.
2. Условия BLACK20 (скидка 20% на весь заказ до 30.11, только на сайте) взяты из вчерашнего письма и креативов, клиент их письменно не подтверждал. Если промокод не суммируется с ценами акции, подписи под ценами не меняем: в письме нет цены «с промокодом».
3. Ссылка на статью «Подарок маме по бюджету» работает с 26.11 18:00 (отложенная публикация).
4. Макрос отписки `#UNSUBSCRIBE_LINK#` сверить с редактором Битрикс24.
5. Тестовое письмо себе: Gmail, Яндекс, Mail.ru, телефон.
