## Смежные категории (30 шт., тексты баннеров — черновики)

- Два типа покупателей: «технарь» (кофемашина, пылесосы) — электроинструмент, автоэлектроника, проекторы, бритвы; «хозяйка / ЗОЖ» (аэрогриль, швабра, виброплатформа) — уборка, кухня, косметика, БАДы, питомцы, дети.
- Перехват конкурентов (своя категория): капсульные кофемашины, пароочистители, моющие пылесосы.
- Приоритет из файла: кофе → капсульные кофемашины, проекторы, автоэлектроника; пылесосы → моющие пылесосы, роботы для окон, владельцы питомцев.
- Все 44 заголовка и подзаголовка укладываются в 18 / 42 символа.

## Что поправить в файле
1. «Любые капсулы» / «Капсулы и молотый кофе в одной машине» — по карточке CoffeeMaker Classic берёт капсулы формата Nespresso, чалды и молотый, не любые. По правилам Ozon это недостоверное обещание.
2. «Роботы для мойки окон» записаны как смежная категория для пылесоса, но робот-мойщик uClean Max — товар Luxhommè: это своя категория (перехват), и её нет в портрете покупателя.
3. Колонка «Для вашей» на листе «Цифры смежных» расходится с «Портрет смежных»: фены (кофеварки/пылесосы ↔ паровая швабра), ножи (пылесосы ↔ аэрогриль), вакуумные упаковщики (кофеварки ↔ аэрогриль), корма (утюги/тренажёры ↔ пылесос/швабра), электроинструмент.
4. Данные Ozon нетипичны (пол определён у 100%): категория «Пылесосы», садовый декор, фитнес и йога, спортпитание — пол не фильтровать.
5. «Моет ламинат минимумом воды», «Виброплатформа для тонуса и упругости» — сверить с карточками; второе ближе к обещанию результата для тела.
6. Электрические чайники — в нашем списке 15 SKU их нет; уточнить, есть ли такой товар.
