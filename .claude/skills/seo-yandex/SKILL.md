# SEO под Яндекс — чек-лист

Использовать вместе со скиллом `seo-audit` (Google-база) и `schema`. Здесь только то, что у Яндекса отличается.

## Как проверять из этой среды
- `curl` + собственный краулер по sitemap: коды ответов, title/description/H1/canonical/robots, JSON-LD, alt.
- Несуществующие URL (`/xyz`, `/blog/xyz`, `/products/xyz`) должны отдавать **404**. Next.js часто отдаёт 200 — это soft 404.
- PageSpeed API без ключа быстро упирается в квоту; браузер через прокси может не доверять CA — тогда CWV пометить «не замерено» и попросить данные из Вебмастера / PSI.
- WebSearch — американский индекс; выдачу Яндекса по нему не оценивать, только факты наличия.

## Индексация и робот
- [ ] Сайт подтверждён в Яндекс Вебмастере, sitemap добавлен, «Страницы в поиске» без массовых исключений.
- [ ] robots.txt: `Host` не нужен (игнорируется с 2018), главное зеркало — через 301 и Вебмастер.
- [ ] `Clean-param` для utm_*, yclid, gclid, from и т.п. (Яндекс склеивает дубли по нему быстрее, чем по canonical).
- [ ] Главное зеркало: http→https, www→без www (сертификат на www обязателен, иначе редирект не сработает).
- [ ] Soft 404: мусорные URL → 404 (Яндекс массово индексирует 200-страницы).
- [ ] Доступность из российских сетей (Cloudflare/антибот не режет YandexBot и пользователей РФ без VPN).
- [ ] Метрика установлена (поведенческие факторы и данные в Вебмастере).

## Коммерческие факторы (сильнее, чем в Google)
- [ ] Каталог с категориями под коммерческий спрос (отдельный URL на категорию, текст, фильтры, сортировка).
- [ ] На карточке: цена, наличие, кнопка купить, доставка/оплата/гарантия рядом, отзывы, характеристики, фото/видео.
- [ ] Контакты: телефон, адрес, реквизиты, режим работы, карта; страницы доставки/оплаты/возврата/гарантии.
- [ ] Ассортимент: широта каталога, похожие/сопутствующие товары.

## Яндекс-сервисы
- [ ] Яндекс Бизнес (карточка организации, Товары и цены) + YML-фид → товарные блоки и «Товары» в выдаче.
- [ ] Регион сайта в Вебмастере (или «без региона» для доставки по РФ).
- [ ] Быстрые ссылки и сниппеты: уникальные description, Product/Offer/AggregateRating/FAQ разметка, favicon.
- [ ] ИКС и упоминания бренда (Дзен, VK, маркетплейсы, обзоры) — проверить в Вебмастере.

## Семантика
- Частоты — Wordstat (Яндекс), не Google Keyword Planner.
- Брендовые и товарные запросы в РФ забирают маркетплейсы: сайту нужны категории + инфоконтент «как выбрать», ведущий на карточки.
