### Что выяснилось

- **Title статьи** на витрине = заголовок записи WP + « | Luxhommè». Заголовок Yoast витрина не использует. Укоротить title можно только сменой заголовка записи, а это меняет и H1.
- **Description статьи** на витрине = «Отрывок» записи, если пуст, то первая строка текста. Описание Yoast витрина не использует.
- **Галерея товара** выводит `alt=""` у всех фото, кроме первого (у него название товара), хотя Store API WooCommerce отдаёт alt из медиатеки (`images[].alt`). Нужна правка витрины: задача в ТЗ, раздел «Дополнения 26.11».
