## Правила работы
- Язык — русский.
- Цифры только из скринов и выгрузок клиента; нет данных — так и сказать.
- Суммы перепроверять (по дням и по строкам).
- ЯД и ЯМ не смешивать; контент-завод — отдельно.
- Вторичные метрики (ДРР, CTR, конверсии, средний чек, CPO, цена просмотра) — только формулами из `metrics.md`.
- Таблицы — без лишних комментариев.
- Новые данные — в `data/ГГГГ-ММ.md`.
- На сайте ничего не менять без подтверждения. Пароли и ключи в чат не просить и не выводить: только переменные окружения (`LUXHOMME_WP_USER`, `LUXHOMME_WP_APP_PASSWORD`, `LUXHOMME_WC_KEY`, `LUXHOMME_WC_SECRET`). Вебхук Битрикс24 — тоже секрет.

- Подтвердить «Выгода до 50%» на баннерах — реальная скидка на момент показа.

- Автописьма Битрикс24: тариф, кто подключает (разработчик или сервис-посредник), отключение дублирующих писем WooCommerce, галочка согласия на рекламу.

## Ограничения инструментов
- Google Drive через подключение: скачивание до 10 МБ, загрузка бинарных файлов (видео, архивы) не работает — файлы отдаются в чат, пользователь загружает сам.
- Figma: тариф Starter, лимит запросов через подключение быстро заканчивается — скачивать нужное сразу.
- Сайт luxhomme.store иногда рвёт соединения — запросы с повторами.
