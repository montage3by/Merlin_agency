# Communication Plan — Acceptance Checklist

- [ ] Every stakeholder in the stakeholder register appears at least once in the communication matrix.
- [ ] Every row in the communication matrix has an assigned information type, cadence, channel, and owner — no cell is left blank.
- [ ] All four escalation types (technical blocker, scope change, budget variance, stakeholder dispute) have a named or role-identified escalation target and a resolution window.
- [ ] All recurring project meetings are listed in the meeting cadence table with audience, purpose, frequency, duration, and facilitator.
- [ ] The documentation hygiene section records where the decision log and status reports live and who maintains meeting minutes.
- [ ] The language column in the communication matrix reflects the `language.output` value from `.pm-kit.config.json`, and any multi-language stakeholder considerations are noted.
- [ ] The artifact cites the canonical reference URL (`https://en.wikipedia.org/wiki/Communications_management`).
- [ ] The "Source consulted" section records which mode was used (offline or online) and does not include fabricated quotations or page numbers.
- [ ] The facilitation dialogue is in the language at `language.communication`, and the saved artifact is in the language at `language.output` (falling back to `language.communication` if `language.output` is absent or empty).
- [ ] The artifact is saved to `docs/pm-kit/outputs/communication-plan/<slug>.md` and begins with the three-line provenance header.

> Mark **PASS** or **FAIL**. On **FAIL**, return to the skill with notes.
