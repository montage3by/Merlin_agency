# Медийка Ozon — недельная таблица расходов (паттерн)

Регулярная задача: раз в неделю собрать расходы медийной рекламы Ozon (два кабинета) в формате общей таблицы затрат (`raw/primer-format.xlsx`, лист «Лист1»).

## Что присылает пользователь
1. Пример формата — общая таблица затрат (Артикул · Дата рекламы · Затраты c НДС · б/НДС · Площадка · Комментарии · Неделя · Месяц).
2. Выгрузки «Статистика по кампаниям» из кабинетов 1 и 2 за неделю — в них только итог за период, без разбивки по дням.
3. Расход по дням по каждому кабинету (скрины или выгрузки) — нужен для строк по дням.

## Как считать
- Расход дня = каб 1 + каб 2.
- Делим на 5 и пишем одинаковую сумму каждому из 5 артикулов: **SHVPAREKCHB, SHVPAR7V1CH, VACCLCOMPACT, VACCLDRY, AEROGRIL2CHASHI** (как в общей таблице с 05.10).
- Копейки отбрасываются, а не округляются: 1 717,63 → 1 717, 1 588,88 → 1 588 (так в общей таблице).
- Строки идут блоками: артикул × все дни недели, в порядке артикулов выше.
- Колонки как в примере: Площадка — «Озон», Комментарии — «Медийная реклама», б/НДС — `=IF(F= "директ", C/1.22, C)`, Неделя — `=ISOWEEKNUM(B)`, Месяц — `=MONTH(B)`.
- Итог недели по дням сверяется с суммой выгрузок двух кабинетов (лист «Расход по дням», строки «Сверка» и «Разница»).

## Как собрать
```
echo "19.10.2026;4600,42;3336,74" > days.csv   # по строке на день: дата;каб1;каб2
PYLIB=<путь к openpyxl> python3 -I scripts/build_week.py days.csv Luxhomme_Ozon-media_<даты>.xlsx raw/<неделя>/export_1.xlsx raw/<неделя>/export_2.xlsx
```
Результат — `Luxhomme_Ozon-media_<даты>.xlsx`: лист «Медийка» (строки для вставки в общую таблицу) и «Расход по дням» (дни, ÷5, сверка).
