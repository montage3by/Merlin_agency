# SEO-аудит luxhomme.store — чек-лист доработок

Дата: 09.10.2026 · Рынок: Россия (Яндекс + Google) · Сайт: Next.js, 26 URL в sitemap, ~50 статей в блоге, 14 товаров

---

## Краткий обзор

### Что хорошо
- **Техническая база в порядке.** HTTPS с HSTS, http → https через 301, gzip, серверный рендеринг: текст страниц сразу в HTML и виден роботам.
- **robots.txt настроен грамотно.** Корзина, профиль, поиск и API закрыты, sitemap указан, AI-боты (GPTBot, ClaudeBot, Perplexity) открыты.
- **Метатеги заполнены везде.** У всех страниц уникальные title и description, есть canonical. URL с utm склеиваются canonical'ом с чистым адресом.
- **Карточки товаров сильные.** Объёмные страницы (на части карточек 1 500–2 500 слов вместе с отзывами), описания, характеристики, видео, инструкции, отзывы с маркетплейсов. Есть микроразметка Product + Offer (цена, наличие, SKU) и хлебные крошки.
- **Блог уже есть, и он большой.** Около 50 статей под информационные запросы («как выбрать паровую швабру», «аэрогриль или духовка» и т.д.) с разметкой Article, FAQ и хлебных крошек.
- **Сильные коммерческие факторы для Яндекса.** Есть страницы доставки, гарантии, возврата и оферты, контакты с реквизитами юрлица, поддержка в Telegram/MAX.
- **Картинки отдаются в современных форматах** (WebP/AVIF через next/image).

### Что плохо
- **Сайт генерирует бесконечные дубли.** Любой несуществующий адрес отдаёт 200 вместо 404, а `/blog/<что угодно>` ещё и открыт к индексации с canonical на самого себя.
- **Блог не участвует в поиске так, как мог бы:**
  - ни одной статьи нет в sitemap;
  - на товары ссылаются только 3 статьи из 50;
  - 6 пар статей дублируют друг друга по теме и конкурируют между собой в выдаче.
- **Нет категорийных страниц под коммерческий спрос.** Например, у запроса «вертикальный моющий пылесос» около 190 тыс. показов в месяц, но сайту нечего показать по нему, кроме одной карточки.
- **Ошибки в структуре заголовков на всех страницах:**
  - H1 главной — «— Готовка с радостью»;
  - первый H2 на каждой странице — «Сравнение разных категорий невозможно» (текст скрытого окна);
  - у страницы `/blog` вместо своего H1 — заголовок одной из статей.
- **Около 90% картинок без alt:** 3 674 из 4 076.
- **Тяжёлые карточки товаров.** HTML до 490 КБ, до 275 картинок грузятся без lazy-load.
- **Ошибки в sitemap.** В нём нет блога и товара CremaX.
- **Сервер периодически обрывает соединение.** В наших замерах это 1–2 запроса из 10, на любых страницах, включая главную.
- **Нет SSL-сертификата на www.luxhomme.store.** Пользователь, набравший адрес с www, видит ошибку.
- **По брендовым товарным запросам сайт не виден:** выдачу забирают Яндекс Маркет, М.Видео и карточка в Яндекс Картах.

### Что не удалось проверить
- **Core Web Vitals (скорость).** PageSpeed API упёрся в лимит, браузерный замер из этой среды не прошёл. Нужны данные из PageSpeed Insights или Яндекс Вебмастера / Search Console.
- **Индексация и позиции.** Нужен доступ к Яндекс Вебмастеру и Google Search Console.
- **Метрика.** Счётчик в исходном HTML не найден. Возможно, он грузится после согласия на cookie, но это нужно проверить.

## Чек-лист

Приоритеты: 🔴 критично (мешает индексации), 🟠 важно (влияет на позиции и трафик), 🟡 улучшения.

### 🔴 1. Индексация и дубли

- [ ] **Отдавать 404 для несуществующих страниц.** Сейчас `/nonexistent-page-xyz` → 200 (index, follow), `/products/net-takogo` → 200 (noindex), `/blog/net-takoy-stati` → 200, index, follow, canonical на самого себя.
  - Как: в Next.js вызывать `notFound()` в `app/blog/[slug]/page.tsx`, `app/products/[slug]/page.tsx` и в catch-all роуте, если запись не найдена.
  - Проверка: `curl -I https://luxhomme.store/blog/test123` → `404`.
- [ ] **Проверить стабильность сервера.** В наших замерах 1–2 запроса из 10 обрывались с ошибкой «connection reset» на разных страницах, включая главную и `/offer`. Возможно, это особенность нашей сети, поэтому нужно проверить:
  - в Яндекс Вебмастере: «Проверка ответа сервера» и «Диагностика» (раздел о недоступности);
  - в логах Apache и Next.js: обрывы, перезапуски процесса, лимиты соединений, работа антибота.
- [ ] **Добавить в sitemap все статьи блога (~50 URL) и товар `/products/cremax`.** Сейчас в sitemap только 26 адресов, блога там нет вообще.
  - `lastmod` ставить по реальной дате изменения материала. Сейчас у всех страниц стоит время генерации sitemap, и поисковики такой lastmod игнорируют.
- [ ] **Выпустить SSL-сертификат на `www.luxhomme.store` и настроить 301 → `https://luxhomme.store/`.**
- [ ] **Проверить доступность сайта из российских сетей без VPN.** В интервью с покупателем 07.07 команда Luxhomme не смогла открыть сайт без VPN. В CSP подключена проверка Cloudflare (challenges.cloudflare.com). Если она режет пользователей или YandexBot из РФ, это прямой удар по индексации в Яндексе.
  - Проверка: Яндекс Вебмастер → «Проверка ответа сервера», плюс открыть сайт с мобильного интернета РФ.
- [ ] **Подтвердить сайт в Яндекс Вебмастере и Google Search Console, отправить sitemap.** Если уже сделано, выгрузить отчёты по исключённым страницам.
- [ ] **Добавить в robots.txt `Clean-param` для Яндекса:**
  ```
  User-Agent: Yandex
  Clean-param: utm_source&utm_medium&utm_campaign&utm_content&utm_term&yclid&gclid&from
  ```
  Директиву `Host` можно убрать: Яндекс игнорирует её с 2018 года.
- [ ] **Проверить, что Яндекс Метрика стоит на сайте.** Если она грузится только после согласия на cookie, данных о поведении будет мало.

### 🟠 3. Заголовки и метатеги

- [ ] **H1 главной.** Сейчас H1 — «— Готовка с радостью»: это строка анимации, и на старте она невидима (opacity:0). Нужен H1 со смыслом, например «Luxhommè — бытовая техника для дома: уборка, кухня, забота». Анимацию оставить на `<p>` или `<span>`.
- [ ] **Убрать H2 «Сравнение разных категорий невозможно» со всех страниц.** Это текст всплывающего окна сравнения, и в структуре страницы он стоит первым H2. Заменить тег на `<p>` или `<div>`.
- [ ] **H1 на `/blog`.** Сейчас H1 — заголовок одной из статей. Нужен «Блог Luxhommè: советы по уборке, кухне и уходу за собой», а заголовки статей в списке сделать H2/H3.
- [ ] **Title товаров укоротить до 55–65 символов и не дублировать бренд.** Сейчас 11 из 25 title длиннее 60 символов, а «Luxhommè» встречается дважды. Шаблон: `{Тип} {Модель} — купить, цена {X} ₽ | Luxhommè`.
  - Пример: «Паровая швабра EcoSteam Pro — купить, цена 5 990 ₽ | Luxhommè».
- [ ] **Исправить опечатку в карточке виброплатформы:** «виброплатформу **длю похудению**» → «для похудения» (в title, description и названии).
- [ ] **Description укоротить до 140–160 символов.** Сейчас у 14 страниц больше 160. Шаблон: тип + 2–3 главных преимущества + доставка/гарантия.
- [ ] **og:image** добавить на главную, «О нас», «Контакты», «Мы на маркетплейсах», «Доставка», «Сервис» и правовые страницы. Без него ссылки в мессенджерах и соцсетях уходят без картинки.
- [ ] **Название и URL паровой швабры AirSteam Pro не совпадают:** URL `/products/steamly-pro`, а товар называется AirSteam Pro. При смене URL обязательно ставить 301 со старого адреса.
- [ ] **Короткие URL без ключевых слов** (`/products/coffee`, `/window`, `/airgrill`, `/sc-100`). Если менять, то только с 301-редиректами и после того, как появятся категории. Приоритет низкий: выигрыш небольшой, риск потерять накопленное есть.

### 🟠 4. Микроразметка (schema.org)

  - Это даёт звёзды рейтинга в сниппетах Яндекса и Google.
- [ ] **Organization:**
  - `logo` в PNG/JPG (сейчас SVG, Google его не принимает);
  - `sameAs` со ссылками на Telegram, VK, Дзен, YouTube, Ozon, WB, ЯМ (сейчас массив пустой);
  - `contactPoint` (email, Telegram-бот), `legalName`, `address`.
- [ ] **WebSite → SearchAction** ведёт на `/search`, а `/search` закрыт в robots.txt. Либо убрать SearchAction, либо открыть страницы поиска с `noindex`.
- [ ] **Категорийные страницы (после создания):** `CollectionPage` + `ItemList` + `BreadcrumbList` + `FAQPage`.
- [ ] Проверить итог в [Rich Results Test](https://search.google.com/test/rich-results) и в Яндекс Вебмастере («Валидатор микроразметки»).

### 🟠 5. Изображения и скорость

- [ ] **Прописать alt всем товарным фото** (сейчас 3 674 из 4 076 картинок без alt). Шаблон: `{Название товара} — {что на фото}` (вид спереди, в комплекте, в работе на кафеле…). Декоративным иконкам — пустой `alt=""` (так уже сделано).
- [ ] **Lazy-load для галерей и отзывов.** На карточке EcoSteam Pro 275 картинок грузятся сразу. Сразу оставить только главное фото (`priority`), остальным — `loading="lazy"`, а фото из отзывов подгружать при прокрутке.
- [ ] **Облегчить HTML карточек.** Сейчас 160–490 КБ, а самый тяжёлый HTML у страниц с большим числом отзывов и картинок. Отзывы выводить порциями (первые 5–10 + «Показать ещё»), галерею — по требованию.
- [ ] **Замерить Core Web Vitals** в [PageSpeed Insights](https://pagespeed.web.dev/) для главной, `/catalog` и 2–3 карточек (мобильная версия) и в отчёте Вебмастера «Качество сайта». Цели: LCP < 2,5 с, INP < 200 мс, CLS < 0,1.
- [ ] **TTFB около 0,8–1 с** (замер не из РФ). Проверить из России. Если больше 0,6 с, увеличить время кэша страниц: сейчас `s-maxage=120`, для карточек можно 600–3600 с с ревалидацией.
