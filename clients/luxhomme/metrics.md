# Формулы и таблица

## Формулы

| Метрика | Формула |
|---|---|
| ДРР | Расходы / Выручка × 100% |
| ДРР средневзвешенный | Σ Расходов / Σ Выручки × 100% |
| CTR | Клики / Просмотры |
| Конв. клики→корзины | Корзины / Клики |
| Конв. корзины→заказы | Заказы / Корзины |
| Средний чек | Выручка / Заказы |
| Цена просмотра | Расходы / Просмотры |
| CPO | Расходы / Заказы |
| Разница в % | (Новое − Старое) / Старое × 100% |

Вторичные метрики — всегда формулами (в таблице тоже), никогда вручную.
