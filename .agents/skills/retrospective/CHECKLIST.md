# Sprint Retrospective — Acceptance Checklist

- [ ] The metadata header records the sprint or iteration identifier, the date, the facilitator, the attendees, and the lens used (default Start/Stop/Continue, or the chosen alternative).
- [ ] The Context section states the sprint goal and whether it was achieved in full, partially, or not at all.
- [ ] Each of the three "what" sections (went well, didn't go well, learned) contains at least one specific, example-grounded bullet — no generic affirmations, no synonyms of items in another section.
- [ ] The "What didn't go well" section describes systems, processes, or conditions; no bullet names or blames an individual.
- [ ] Psychological safety was addressed during facilitation: if participation thinned, the facilitator offered an anonymously-phrased prompt and any answers captured in the artifact are attribution-free.
- [ ] Every Action items row has a non-empty Owner, a non-empty Due date, and a non-empty Success criteria — no orphan actions, no TBDs, no "owner: team" catch-alls.
- [ ] Each action item targets something from the "What didn't go well" or "What we learned" section; none targets an item under "What went well."
- [ ] The Follow-up section marks each previous retro action Resolved, In progress, or Dropped with rationale — or the section reads `First retrospective — no prior items.`
- [ ] The output cites the canonical Scrum Guide URL (`https://scrumguides.org/scrum-guide.html`) in the Source consulted section.
- [ ] The Source consulted section records which mode was used (offline or online) and does not include fabricated quotations or page numbers.
- [ ] The facilitation dialogue is in the language at `language.communication`, and the saved artifact is in the language at `language.output` (falling back to `language.communication` if `language.output` is absent or empty).
- [ ] The artifact is saved to `docs/pm-kit/outputs/retrospective/<slug>.md` and begins with the three-line provenance header.

> Mark **PASS** or **FAIL**. On **FAIL**, return to the skill with notes.
