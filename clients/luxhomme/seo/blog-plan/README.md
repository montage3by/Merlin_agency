## Требования к каждой статье

- HTML-статья в блоге, H1 из плана, title до 60 символов, description до 160 символов с ценой «от … ₽» или выгодой.
- Блок товара с ценой и кнопкой «В корзину» после первого экрана и в конце; цены тянуть из каталога, не вписывать руками.
- 2–3 ссылки на статьи блога из таблицы и ссылка на хаб 01.12 из всех новогодних статей.
- В руководствах по моделям: подзаголовки под реальные вопросы («Как включить музыку», «Насадка для окон», «Что делать, если…»), блок FAQ, ссылка на PDF для скачивания.
- Разметка Article и FAQPage, alt у всех картинок, статья в sitemap.
- В день публикации: переобход в Вебмастере, анонс в Дзене и Telegram-канале.
