# E-commerce UX — чек-лист по сценариям покупки

Работает в связке: `nielsen-heuristics-audit` (общие эвристики и шкала серьёзности 0–4), `wcag-accessibility-audit` (доступность), `web-design-guidelines` (правила вёрстки), `cro` (оффер, CTA, доверие). Здесь — то, что специфично для магазина.

## Как собирать доказательства
- Скриншоты десктоп 1366px и мобайл 390px для: главной, каталога, карточки (2 разных типа), корзины пустой/с товаром, чекаута до оплаты, 404, поиска.
- Пройти сценарий руками: найти товар → сравнить → в корзину → оформить (до оплаты, не платить).
- HTML/CSS смотреть на: alt, label у полей, aria у иконок, viewport, размеры тап-зон, lazy-load.
- Если браузер недоступен — фиксировать, что выводы только по HTML, и не утверждать про визуал.

## 1. Главная и навигация
- [ ] За 5 секунд понятно: что продают, для кого, почему здесь, а не на маркетплейсе.
- [ ] Каталог в шапке с категориями (не только «Каталог»), поиск виден сразу (на мобайле — иконкой в шапке).
- [ ] Хиты/категории на первом экране, а не только имиджевый слайдер.
- [ ] Доверие на первом экране или рядом: гарантия, доставка по РФ, рейтинг с маркетплейсов, официальный бренд.

## 2. Каталог / листинг
- [ ] Категории и фильтры по реальным критериям выбора (тип, мощность, объём, цена), сортировка (популярные, цена).
- [ ] Карточка в листинге: фото, название с типом товара, цена (+ старая цена), рейтинг/кол-во отзывов, ключевые 2–3 характеристики, «В корзину» без перехода.
- [ ] «Показать ещё»/пагинация не теряют позицию при возврате назад.
- [ ] Сравнение товаров: работает между моделями одного типа, понятно, где список сравнения.
- [ ] Пустые результаты фильтра/поиска — с подсказкой, а не пустой экран.

## 3. Карточка товара
- [ ] Над сгибом: название, цена, наличие, срок доставки, «В корзину» / «Купить в 1 клик», рейтинг.
- [ ] Галерея: зум, видео, фото в масштабе/в интерьере; на мобайле свайп.
- [ ] Ключевые преимущества списком до длинного описания; характеристики — таблицей.
- [ ] Отзывы: средняя оценка, количество, фото покупателей, сортировка/фильтр; источник (маркетплейс) указан.
- [ ] Ответы на возражения рядом с кнопкой: гарантия, возврат, доставка, оплата частями/СБП.
- [ ] Комплектация, «что в коробке», совместимость (капсулы, насадки), расходники и аксессуары.
- [ ] Цена на сайте vs маркетплейсы: если дороже — дать причину купить здесь (бонусы, гарантия, подарок); если есть ссылки на маркетплейсы — не уводить с сайта раньше, чем человек решил.
- [ ] Липкая кнопка покупки на мобайле.

## 4. Корзина
- [ ] Видно, что товар добавлен (мини-корзина/тост), счётчик в шапке обновился.
- [ ] Изменение количества, удаление с undo, итог с доставкой или понятным «рассчитаем на следующем шаге».
- [ ] Промокод/бонусы — не отвлекает (свёрнуто), но доступно.
- [ ] Кросс-селл аксессуаров (насадки, фильтры, капсулы).

## 5. Чекаут
- [ ] Гостевой заказ без обязательной регистрации.
- [ ] Минимум полей, автозаполнение (`autocomplete`), маска телефона, правильные `type`/`inputmode`.
- [ ] Доставка: ПВЗ на карте, курьер, сроки и стоимость до ввода всех данных; для РФ — подсказки адреса (DaData/Яндекс).
- [ ] Оплата: карта, СБП, Яндекс Пэй/Сплит/долями; итог виден на каждом шаге.
- [ ] Ошибки инлайн, понятным языком, фокус на первой ошибке.
- [ ] Согласие на ПДн и оферта — без лишних галочек, ссылки открываются в новой вкладке.

## 6. Аккаунт, сервис, доверие
- [ ] Статус заказа, история, бонусы клуба — понятно, что дают и как потратить.
- [ ] Контакты: телефон/мессенджеры кликабельны, режим работы, юрлицо.
- [ ] Гарантия/возврат — коротко и по шагам, с кнопкой «Оформить возврат».

## 7. Мобайл и доступность (быстрые проверки)
- [ ] `viewport` без запрета зума (`maximum-scale=1`, `user-scalable=no` — нарушение).
- [ ] Тап-зоны ≥ 44×44, расстояние между ними.
- [ ] Шрифт ≥ 16px в полях (иначе iOS зумит), контраст ≥ 4.5:1.
- [ ] Модалки/попапы (cookie, чат, промо) не перекрывают кнопку покупки и закрываются.
- [ ] Чат-виджет не закрывает липкую кнопку и корзину.

## Формат вывода
Обзор (что хорошо / что плохо) → чек-лист по разделам выше с приоритетом 🔴/🟠/🟡 и серьёзностью по Нильсену (0–4) → «быстрые победы» → гипотезы для A/B (см. `ab-testing`).
