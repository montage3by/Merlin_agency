# Рассылка «Закрытая распродажа −15%» (Битрикс24, октябрь 2026)

- `email.html` — письмо (600 px, табличная вёрстка, inline-стили, адаптив, кнопки для Outlook).
- `images/` — картинки (≈0,5 МБ), `preview.jpg` — десктоп и мобайл.
- `scripts/hero.mjs` — обложка и логотип со шрифтами сайта (Inter + Gogol); `scripts/build_email.py` — сборка письма и картинок.

Стиль сайта: фон #efeeeb / #e1dfda, текст #2a2a2a, акцент #e7ae90 (кнопка — тёмный текст для контраста), серии: Уборка #86adea, Кухня #e7ae90, Забота #a9cb73. Шрифт письма — Helvetica Neue → Helvetica → Arial (как на сайте); рукописный Gogol только в картинке обложки.

## Перед отправкой
1. Промокод `CLOSED15` — заглушка. Один код на всех — заменить в `build_email.py` (PROMO) и пересобрать. Уникальные коды — загрузить в поле контакта и вставить его макрос через «Персонализация».
2. Картинки должны лежать по публичным ссылкам: загрузить папку `images/` на сайт (например, `luxhomme.store/email/2026-10/`) и пересобрать с адресом последним аргументом, либо заменить каждую картинку в редакторе Битрикс24.
3. Ссылка отписки — `#UNSUBSCRIBE_LINK#`: сверить с макросом в редакторе Битрикс24.
4. Цены в подборке сняты с сайта 12.10.2026; цена «с промокодом» = цена × 0,85 с округлением — сверить на тестовом заказе.
5. Тестовое письмо себе: Gmail, Яндекс, Mail.ru, iPhone.

UTM: `utm_source=bitrix&utm_medium=email&utm_campaign=closed_sale_2026_10&utm_content=<блок>`.
